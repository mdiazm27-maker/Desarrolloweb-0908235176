DOCUMENTACIÓN DE SOLUCIÓN - BUGFIX

Este archivo documenta los pasos realizados para crear, publicar y sincronizar la rama bugfix/ramas-github.

1. Regresar a la rama main

git checkout main

2. Crear la rama bugfix

git checkout -b bugfix/ramas-github

3. Publicar la rama en GitHub

git push -u origin bugfix/ramas-github

4. Crear el archivo DocumentacionSolucion.txt dentro de la carpeta RamasGitHub.

5. Agregar el archivo para realizar el commit

git add DocumentacionSolucion.txt

6. Crear el commit

git commit -m "Agregar documentacion en bugfix"

7. Publicar los cambios de la rama

git push

8. Integrar los cambios de bugfix en main

git checkout main
git merge bugfix/ramas-github

9. Publicar nuevamente main

git push

Resultado:

La rama bugfix/ramas-github fue creada y publicada correctamente. El archivo DocumentacionSolucion.txt fue agregado mediante un commit y posteriormente sus cambios fueron integrados a la rama main.
